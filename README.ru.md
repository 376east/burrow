# Burrow

[English](README.md) · [Архивные установщики](https://github.com/376east/burrow/releases/tag/v0.13.0)

Настольный лаунчер Minecraft. Выбирайте версию игры и модлоадер, устанавливайте модпаки Modrinth и управляйте модами и мирами из одной библиотеки.

## Запуск

Текущий предпросмотр запускается из исходников. Установщики по ссылке выше относятся к архивной версии 0.13.0.

Нужны Node.js 24 и npm 11.

```sh
git clone https://github.com/376east/burrow.git
cd burrow
npm ci
npm run dev
```

Вход через Microsoft и Quilt пока недоступны. [Ограничения](docs/ru/known-issues.md)
