# Repository and versions

The public [Burrow repository](https://github.com/376east/burrow) uses the `master` branch. [Releases](https://github.com/376east/burrow/releases) lists installers and their version tags. [Development](en/development.md) explains how to work from source.

Earlier source revisions remain in Git. For example, [the revision before the Next migration](https://github.com/376east/burrow/commit/241578e09a2540f7a4685927a929ef972dbf0777) is available by commit ID.
