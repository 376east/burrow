# Демо Burrow Next

[Ролик с озвучкой, 45 секунд](assets/demo/burrow-next-demo.mp4). Источник - код `f74c19b783a8c78440824260ed752c5d16bb354e`, версия Next.6. [Provenance](assets/demo/provenance.json) содержит SHA-256, сценарий данных и выполненные проверки. Это запись настоящего renderer/main в stock Electron; не запись установленного NSIS-пакета и не игровой запуск.

## Что показано

Играть → библиотека → детали и настройки сборки → «Вместе» и раскрытие гайда → настройки → светлая тема → возврат в тёмную. Окно 1280 × 900. Три исходные синтетические записи: «Мир с друзьями», «Своя сборка», «Vanilla +», Minecraft 1.21.1/Vanilla, 6 ГБ. Каталоги игры пустые. Нормализация состояния приложения может добавить встроенную запись Vanilla.

Запись не нажимает «Играть», не скачивает Minecraft, не входит в настоящий аккаунт и не соединяет двух игроков. Лаунчер при запуске может получать публичные списки версий. Только описание показанного можно считать подтверждённым демо.

## Переснять

Нужны Node/npm проекта, установленный Electron/Playwright, Python 3.11+ и `ffmpeg`/`ffprobe` в PATH. Дополнительная Python-зависимость: [requirements.txt](../scripts/demo/requirements.txt), Edge TTS 7.2.8. Голос - `ru-RU-SvetlanaNeural`, темп `+5%`. Сервис требует интернет и может быть недоступен; в него отправляется только публичный текст из [assemble.py](../scripts/demo/assemble.py).

```bash
npm ci
npm run build -- --publish never
python -m venv work/demo-venv
```

Windows PowerShell:

```powershell
work/demo-venv/Scripts/python.exe -m pip install -r scripts/demo/requirements.txt
node scripts/demo/record.mjs work/demo
work/demo-venv/Scripts/python.exe scripts/demo/assemble.py work/demo
```

macOS/Linux:

```bash
work/demo-venv/bin/python -m pip install -r scripts/demo/requirements.txt
node scripts/demo/record.mjs work/demo
work/demo-venv/bin/python scripts/demo/assemble.py work/demo
```

[record.mjs](../scripts/demo/record.mjs) запускает production bundle через stock Electron: пакетные fuses мешают Playwright подключить Node inspector к установленному приложению. Скрипт создаёт новый профиль через `mkdtemp`, засевает синтетические записи, снимает переходы, закрывает приложение и удаляет только созданный им профиль. В каталог вывода попадают raw WebM, снимки и metadata. Это полный автоматизированный сценарий текущего UI; после изменения текста/контролов selectors могут потребовать обновления. Нативный повтор на macOS/Linux пока не проверен.

[assemble.py](../scripts/demo/assemble.py) отрезает подготовительную часть по metadata, кодирует H.264, создаёт отдельные голосовые реплики и добавляет AAC-дорожку. Громкость нормализуется около -16 LUFS, реплики заканчиваются до следующего интервала. Если текст слишком длинный, сборка останавливается; допускается небольшое ускорение реплики. Кадры готового немого ролика копируются без повторного кодирования при добавлении голоса.

Результат: `work/demo/burrow-demo-voice.mp4`. Голос кешируется по хешу текста. Таймлайн - `work/demo/voices/timeline.json`. Старый готовый `burrow-demo.mp4` в этом каталоге переиспользуется: для нового захвата выбери новый каталог, например `work/demo-retake`, а не смешивай записи.

## Ручная проверка перед публикацией

Сборщик проверяет audio stream, длительность, полное декодирование, границы реплик и идентичность видеопотока немому источнику. Это не проверка вкуса и не прослушивание человеком. Открой ролик целиком: голос должен соответствовать экрану, переходы не должны зависать или обрезать фразы. Таймлайн фиксирован под текущий сценарий; при изменении задержек записи проверь его и поправь SCENES в сборщике. Запись не растягивается стоп-кадрами ради длинного текста.

Перед публикацией проверь названия, никнеймы, пути и изображения. Не используй настоящие профили, аккаунты, миры и переписки. В демо публикуется только синтетическое состояние. Для нового результата обнови provenance с фактическим source commit и хешем; не приписывай старому ролику новый HEAD.

Ролик около 3 МБ хранится прямо в Git. Большие будущие ролики лучше прикладывать к отдельному GitHub Release и менять ссылку README; не публиковать установщик как проверенный релиз только ради видео. Права компонентов остаются прежними: [THIRD_PARTY_NOTICES](../THIRD_PARTY_NOTICES.md).
